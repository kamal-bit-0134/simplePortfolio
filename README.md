## Features

- **Bilingual support** — English and German with persistent language preferences.
- **Professional case studies** — Detailed insights into real-world backend development projects.
- **Interactive demonstrations** — API request pacing simulation with adjustable request intervals.
- **Technical visualizations** — Animated architecture and data-flow diagrams.
- **Personal projects** — Selected software projects with custom SVG illustrations.
- **Responsive design** — Optimized for desktop, tablet, and mobile devices.
- **Language-specific CVs** — Downloadable English and German résumés.
- **Accessibility** — Keyboard-friendly navigation and reduced-motion support.
- **Lightweight implementation** — No external frameworks, build tools, or runtime dependencies.

## Running Locally

Clone the repository:

```bash
git clone https://github.com/kamal-bit-0134/simplePortfolio.git
cd simplePortfolio
```

Open `index.html` directly in your browser or start a local development server:

```bash
python3 -m http.server 8000
```

Visit:

```text
http://localhost:8000
```

No package installation or build process is required.

## Internationalization

The website supports English and German through a dedicated `translations.js` file.

Language switching updates the website content and corresponding résumé links without requiring a page reload. The selected language preference is stored locally in the browser.

## Deployment

The portfolio is hosted using GitHub Pages and deployed from the `main` branch.

The previous version of the portfolio is preserved in the `legacy-portfolio` branch.
